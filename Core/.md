# Core Directory

This directory contains the fundamental building blocks of the entire game modification framework. It is designed to be generic, reusable, and completely independent of any specific game content (like NPCs, items, etc.).

## Key Principles:
- **Abstraction**: Provides interfaces and base classes that define the "what" but not the "how".
- **Reusability**: The systems within `Core` (like ECS, DI, Configuration) can be used by any future content without modification.
- **Content Agnostic**: Code in this directory should never reference specific content folders (e.g., `Content/NPCs/NightmareCorruption`).
