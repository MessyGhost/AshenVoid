# Dependency Injection (DI) Directory

This directory contains the custom Dependency Injection (DI) container. The DI container is a powerful tool for managing the creation and lifetime of objects, and for decoupling components from their concrete dependencies.

## Responsibilities:
- **Service Registration**: Allows different parts of the application to register services (classes) and their corresponding interfaces.
- **Dependency Resolution**: Automatically creates instances of services and injects them as dependencies into other objects that require them.
- **Lifetime Management**: Manages the lifetime of the created objects (e.g., Singleton, Transient).
