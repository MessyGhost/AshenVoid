# Stats Directory

This directory contains the core implementation of the dynamic attribute modification system. This system allows for runtime changes to character stats (like damage, defense, speed) from various sources like buffs, debuffs, or special states (e.g., enrage).

## Key Components:
- **`ModifiableStat.cs`**: The heart of the system. It defines:
    - `ModifiableStat`: A class that holds a single stat's base value and a list of `StatModifier`s. It calculates the final, modified value on demand.
    - `StatModifier`: A class representing a single modification (e.g., +10 flat damage, +20% speed). It includes the value, the type of modification (flat, percentage), and the source of the modifier for easy management.
