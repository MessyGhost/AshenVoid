# 属性 (Stats) 目录

## 职责

本目录提供了一个可动态修改的属性系统。在游戏中，一个角色的属性（如攻击力、移动速度）常常会受到多种来源（如Buff、Debuff、装备、特殊技能）的临时或永久影响。本系统旨在以一种清晰、可扩展的方式来管理这些复杂的计算。

## 核心概念与文件

- **`ModifiableStat.cs`**: （这个文件在重构中可能已被简化或移除，但概念依然重要）定义了一个“可修改属性”的核心概念。它包含：
    - **基础值 (Base Value)**: 属性的原始值，不受任何修正影响。
    - **修正列表 (List of Modifiers)**: 一个列表，包含了所有对该属性生效的修正。
    - **最终值 (Final Value)**: 根据基础值和所有修正动态计算出的最终结果。

- **`StatModifier`**: （同上，可能已被简化）代表一个单独的属性修正。它通常包含：
    - **值 (Value)**: 修正的数值。
    - **类型 (Type)**: 修正的类型，如：
        - `Flat`: 直接在基础值上进行加减。
        - `Additive`: 对基础值进行百分比加成（多个Additive修正之间直接相加）。
        - `Multiplicative`: 对经过`Flat`和`Additive`修正后的值进行百分比乘算（多个Multiplicative修正之间直接相乘）。
    - **来源 (Source)**: 修正的来源（如某个Buff），便于追踪和移除。

- **`MovementStats.cs`**: 一个具体的数据容器类，用于存储与移动相关的各种参数，例如二阶动力学的参数、巡逻速度、追击距离等。这个类本身不包含逻辑，只作为配置数据的载体。

## 工作流程

当需要计算一个角色的最终属性时，系统会获取其对应的`ModifiableStat`实例，遍历其修正列表，按照 `Flat -> Additive -> Multiplicative` 的顺序应用所有修正，最终得出一个可以在游戏中使用的确切数值。
