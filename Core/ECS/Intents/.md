# Intents Directory

This directory contains "Intent" objects. Intents are a crucial concept in this framework, acting as the communication bridge between the decision-making parts of the AI (the FSM and Behavior Tree) and the action-executing parts (the Components).

## Key Principles:
- **Data, Not Logic**: Intents are simple data containers. They describe *what* the AI wants to do, but contain no logic for *how* to do it.
- **Decoupling**: By using intents, the Behavior Tree doesn't need to know the implementation details of the `MovementComponent`. It just needs to create a `ChaseIntent` and pass it along.
- **Clarity**: They make the AI's desires explicit and easy to debug.

## Files:
- **`MovementIntents.cs`**: Defines `IMovementIntent` and all concrete movement intents (`ChaseIntent`, `OrbitIntent`, `TeleportIntent`, etc.).
- **`AttackIntents.cs`**: Defines `IAttackIntent` and all concrete attack intents (`ShootProjectileIntent`, `SpawnNpcIntent`, etc.).
