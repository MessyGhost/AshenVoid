# Entity Component System (ECS) Directory

This is the heart of the AI and logic framework. It contains the core implementation of the Entity-Component-System pattern, which favors composition over inheritance.

## Subdirectories:
- **`BehaviorTree`**: Contains the non-blocking Behavior Tree implementation for making tactical decisions.
- **`FSM`**: Contains the Finite State Machine implementation for managing high-level states (e.g., phases of a boss fight).
- **`Intents`**: Holds the data-only "Intent" objects that communicate desired actions from the AI (BT/FSM) to the components.
- **`Interfaces`**: Defines the contracts (`IComponent`, `IMovementComponent`, etc.) that all components must adhere to.

## Core Components:
- **`ComponentController.cs`**: The central authority that creates, updates, and provides access to all components.
- **`AIComponent.cs`**: The primary driver of the AI, responsible for holding and updating the FSM.
- **Other Components (`MovementComponent`, `AttackComponent`, etc.)**: Concrete implementations of the component interfaces, responsible for executing specific logic.
