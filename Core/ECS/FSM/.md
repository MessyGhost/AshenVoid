# Finite State Machine (FSM) Directory

This directory contains the implementation of the Finite State Machine (FSM). The FSM is used to manage the high-level, strategic states of an AI, such as the different phases of a boss fight.

## Key Files:
- **`IState.cs`**: Defines the contract for all state objects. Each state must have `Enter`, `Update`, and `Exit` methods.
- **`StateMachine.cs`**: The engine of the FSM. It holds the current state, manages transitions between states, and calls the appropriate methods on the current state object.
