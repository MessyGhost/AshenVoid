# Interfaces Directory

This directory defines the public contracts for all components in the ECS framework. Interfaces are the foundation of abstraction and decoupling in this system.

## Purpose:
- **Define Contracts**: An interface like `IMovementComponent` specifies *what* a movement component must be able to do (e.g., `SetIntent()`, `IsMoving()`) without dictating *how* it should be done.
- **Enable Dependency Injection**: The DI container uses these interfaces to resolve dependencies. Code should depend on interfaces (`IAttackComponent`), not concrete classes (`AttackComponent`).
- **Promote Swappability**: As long as a new class implements the required interface, it can be swapped in with minimal changes to the rest of the codebase.
