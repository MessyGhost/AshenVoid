# Behavior Tree Directory

This directory contains the implementation of the Behavior Tree (BT). The BT is used to model the tactical, moment-to-moment decision-making of an AI.

## Key Files:
- **`BehaviorTreeNodes.cs`**: Defines the core building blocks of any BT: `Node`, `SequenceNode`, `FallbackNode`, `ActionNode`, `ConditionNode`, etc. This file is generic and contains no game-specific logic.
- **`BTNodes.cs`**: A static helper class that provides a fluent API for constructing BTs that are aware of our ECS framework. It contains methods like `SetChase`, `IsPlayerInRange`, etc., which create nodes that interact with the `ComponentController` to get components and set intents.
