# Configuration Directory

This directory is responsible for loading external configuration files. It allows developers and designers to tweak game parameters without recompiling the code.

## Responsibilities:
- **Loading Data**: Contains loaders for specific file formats (e.g., `.hjson`).
- **Parsing and Validation**: Ensures that the loaded data is valid and can be safely used by the application.
- **Providing Access**: Makes the loaded configuration data available to other systems, typically through the Dependency Injection container.
