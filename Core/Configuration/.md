# 配置 (Configuration) 目录

## 职责

本目录负责从外部文件加载配置，核心目标是**将数据与代码分离**。

通过将Boss的生命值、攻击力、行为参数等数值存储在易于编辑的文本文件（如 `.hjson`）中，游戏设计师和开发者可以在不重新编译整个Mod的情况下，快速调整和测试游戏内容，极大地提高了开发和迭代效率。

## 核心概念与文件

- **`IConfigLoader.cs`**: 定义了配置加载器的接口，规定了所有加载器都必须提供一个 `Load<T>` 方法。
- **`ConfigLoader.cs`**: `IConfigLoader` 的一个具体实现。它能够读取指定路径的 `.hjson` 文件，并将其内容反序列化到一个强类型的C#对象中。

## 工作流程

1.  **定义数据结构**: 在 `Content` 目录的相应位置（例如 `Content/NPCs/NightmareCorruption/Configs/`）创建C#类，这些类的结构必须与 `.hjson` 文件的结构完全对应。例如，`BossConfig.cs`。
2.  **创建配置文件**: 在相同位置创建一个 `.hjson` 文件（例如 `NightmareCorruption.hjson`），并填入具体的数值。
3.  **加载配置**: 在需要使用配置的地方（例如在 `EcsBoss` 的 `BuildEntity` 方法中），创建一个 `ConfigLoader` 的实例，并调用其 `Load<BossConfig>(path)` 方法。
4.  **使用配置**: 加载器会返回一个填充了数据的 `BossConfig` 对象。代码的其余部分就可以直接使用这个对象的属性，而无需硬编码任何数值。

这种方式使得配置的管理变得集中、清晰且易于修改。
