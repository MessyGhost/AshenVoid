# Events Directory

This directory contains the core implementation of the global Event Bus system. This system allows for decoupled communication between different parts of the framework, following a publish-subscribe pattern.

## Key Components:
- **`IEvent.cs`**: A marker interface that all event data structures must implement.
- **`EventBus.cs`**: A singleton service that manages event subscriptions and publications. It allows any part of the system to publish an event, and any other part to subscribe to it without creating direct dependencies.
- **`NPCEvents.cs`**: Contains concrete event classes related to NPC lifecycle, such as `NPCDamagedEvent` and `NPCHealthLossEvent`.

## Workflow:
1. An event source (e.g., the main `ModNPC` class) publishes an event to the `EventBus`.
2. The `EventBus` notifies all subscribers that have registered an interest in that specific event type.
3. Subscribers (e.g., `AIComponent`) execute their handler logic in response to the event.
