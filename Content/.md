# Content Directory

This directory contains all the specific, concrete content of the game modification. Unlike the `Core` directory, which is generic, everything in `Content` is specific to this mod.

## Subdirectories:
- **`Items`**: Contains definitions for all custom items.
- **`NPCs`**: Contains definitions for all custom Non-Player Characters, including bosses and enemies.
- **`Projectiles`**: (If any) would contain definitions for custom projectiles.
- **`UI`**: (If any) would contain custom user interface elements.

## Key Principles:
- **Depends on Core**: Content code *uses* the systems defined in `Core`. For example, an NPC here will use the `ComponentController` and `AIComponent` from `Core/ECS`.
- **Does Not Define Core Logic**: This directory should not contain any reusable, generic framework code. That belongs in `Core`.
