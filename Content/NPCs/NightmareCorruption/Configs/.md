# Configs Directory

This directory holds all configuration related to the `NightmareCorruption` boss.

## Key Files:
- **`NightmareCorruption.hjson`**: The master configuration file. This is where designers can tweak all boss parameters, from health and damage to movement speeds and attack cooldowns. This is the "single source of truth" for boss stats.
- **`BossConfig.cs`**, **`PhaseConfig.cs`**, etc.: These are the C# classes that the `ConfigLoader` uses to deserialize the `.hjson` file. Their structure must exactly match the structure of the HJSON file.
