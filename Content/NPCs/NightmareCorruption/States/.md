# States Directory

This directory contains the concrete FSM state implementations for the `NightmareCorruption` boss. Each file in here represents a major phase or state of the boss fight.

## Responsibilities:
- **Implement `IState`**: Each class must implement the `IState` interface from `Core/ECS/FSM`.
- **Define Behavior Trees**: The primary role of a state object is to build and hold the Behavior Tree that governs the AI's logic during that state. The `Enter()` method is typically where the BT is constructed.
- **Manage State-Specific Logic**: Any logic that is unique to a particular phase of the fight belongs here.
